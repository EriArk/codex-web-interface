## Coverage

The portable suite passes 263 tests. Typecheck, production build, lint and repository-content checks pass on Linux. The targeted regressions pass in Chromium and WebKit. The complete CI browser matrix additionally covers copying, both speech modes, GPT preparation/outbox/history/load recovery, Codex send receipts, queues/Steer, handoff, downloads, previews/isolation, pins and navigation, push/recovery, Files/Git, machine health, Notes, Tasks, Core, Plans, Reports, rotation and Remote input. Windows CI separately verifies Companion runtime isolation with simulated desktop effects.

Runtime inspection found healthy Hub/GPT containers with no container OOM or restart counters and no structured warning/error records in the sampled recent logs. Backup service last result was successful and storage had ample free space. This is a bounded observation, not proof that an intermittent fault cannot recur. The audit itself does not interrupt active work or exercise hard restart on the owner's desktop. Deployment waits until Codex/GPT and command receipts are idle.

## Remaining limits

- Native ChatGPT DOM/browser integration remains sensitive to upstream changes. Its durable uncertain receipts intentionally require reconciliation rather than automatic replay. Recognized optional promotions may be dismissed; unknown/consent/login dialogs remain visible through the protected connection page.
- The owner account has no native ChatGPT Projects for a live project-rotation check. That path is covered by canonical-membership/adapter fixtures, not claimed as live-account acceptance.
- iOS lock-screen audio, keyboard, touch and standalone file sharing still need the owner's physical-device use. Chromium/WebKit and simulated voices do not replace it (#10).
- Full history and native Windows staging are intentionally retained. Quotas, inventory and bounded maintenance exist; indefinite history retention/compaction remains tracked in #5.
- Additional machines, optional GUI launch/screenshot actions and guided distribution remain feature work (#37, #38, #11/#14). The owner-deferred root policy in #6 is unchanged.
