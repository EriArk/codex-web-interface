# Аудит восстановления и лишних действий — 20 сентября 2026

Правило владельца: сначала тихо восстановить, только после неудачи объяснить проблему и предложить действие. Статус внутренней реализации не должен становиться пользовательской задачей.

Это аудит кода и целевые браузерные проверки, не полная аппаратная приёмка iPhone/iPad.

Уже существующие ограничения объёма/страниц сохранены. Не повторяются 401/403/404/409/429, ошибки предметной области, POST/PATCH/DELETE и вход. Запросы fetch для бинарных файлов не изменены.

## Что уже восстанавливается автоматически

- useWorkspace: WebSocket с backoff, возвращение сети и вкладки; сохранённая история при недоступном ПК.
- useGptHistory: периодическое чтение, online/pageshow/visibility, сохранённый кэш.
- GPT каталог/модели: несколько тихих попыток перед loadNotice.
- MessageQueue: ошибки чтения показываются после нескольких неудач, healthy snapshot очищает их.
- Передача загрузок: существующие подтверждённые фрагменты и квитанции; не превращать retry фрагмента в отправку нового сообщения.

## Ручные действия, которые остаются осмысленными

- Неизвестный исход отправки: сначала проверка канонической истории/квитанции; без слепого повторного send.
- «Вернуть в черновик» и конфликт с новым текстом — выбор владельца, не сетевой retry.
- Восстановление версии Canvas/Core, удаление, сброс лимита, запуск плана, публикация, смена владельца исполнения и жёсткий рестарт — реальные изменения, не восстановление связи.
- Вход, bot challenge, согласие, истёкшая авторизация, отсутствие разрешений/исходника и конфликт редакций требуют понятного адресного действия.

## Проверки этого захода

- Целевой тест общей retry-политики: один повтор чтения, без повторной записи/ошибок доступа/rate limit/предметных ошибок; отмена и смена сессии.
- Очередь GPT: пустой чат, работа другого чата, предыдущая running/unknown работа своего чата, завершённая работа.
- Chromium/WebKit: автоматическое подключение Codex, отсутствие плашки в процессе/после успеха, ручной retry после ошибки, сохранение черновика, отсутствие turn/start и restart.
- Сборка Linux. Загрузки крупных файлов и широкие несвязанные тесты не повторялись.
