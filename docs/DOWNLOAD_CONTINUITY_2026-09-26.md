# File saving continuity — 26 September 2026

The previous fix covered Results cards, but the universal Result viewer still used
an independent raw download anchor. Editor snapshots, Save Copy, extracted ZIP
entries, room exports and PC enrollment bundles also bypassed the shared flow.

All of these now use DownloadLink. Local saves pass the exact immutable File;
Result viewers fetch the original source rather than their possibly truncated
preview. System sharing starts from a fresh tap after preparation, with a closable
save window above the mounted parent. Enrollment retains its durable attempt and
requires a save tap after producing the private ZIP. No synthetic delayed anchor
click remains. Room export is explicitly admitted to the existing authenticated
URL allowlist. Space file cards use an internal open button.

Standalone browser fallback opens a separate context without the download
attribute, which iOS can consume within the PWA despite target=_blank. Desktop
browser downloads retain that attribute. Original endpoint authorization, source
identity and bounded preparation/large-file streaming behavior are unchanged.
