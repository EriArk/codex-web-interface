## Вывод

Открытый issue больше нельзя читать как «всё это ещё нужно написать». В списке одновременно лежат уже установленные функции, частичные реализации, исчезнувшие после замены GPT дефекты и новая концепция Team. Старые чеклисты и сведения «пока canary / ждёт установки» не должны запускать повторную разработку.

Ближайшая последовательность: **завершить Results → подготовить независимого участника → роли AI-чатов и Project GPT → новая совместная работа через GitHub → отчёты/входящие → общение и Brainstorm**. Небольшие личные улучшения можно вставлять отдельными проходами. Ниже это рекомендация, а не обещание выполнить весь список одним заходом.

## Что не надо делать заново

- Native GPT уже используется владельцем: обычные чаты, отправка/вложения, история, результаты, относительное управление Remote. Наличие реализации расширенных операций не равно их полной реальной приёмке.
- Промежуточный публичный ход GPT вынесен в нижнюю раскрываемую панель и Results → Рассуждения. Основной GPT-чат оставляет итоговые ответы. **Codex этим изменением не затрагивается.**
- Установлены сохранённая навигация, прогрев активных чатов, кэш закреплённых и последних десяти, метаданные Results, независимые от истории сохранённые модель/мощность.
- Настройки общие для Codex/GPT, лимиты видны в обзоре; Files/Git имеют отдельные окна и кнопки; вкладка «Все» и лишняя подпись проекта удалены.
- Ссылки на существующие файлы/картинки направляются в Results. HTML-демо, копирование и сворачивание кода уже есть. Это ещё не автоматическое создание `.md` из любого поддержанного текстового блока.

## Что ещё не относится к завершённому

- GPT Results по всему проекту: текущая выдача привязана к одному native чату. Нужен ограниченный серверный индекс по правам/членству; нельзя просто читать все чаты при каждом открытии. Не смешивать с долгоживущим Project GPT #200 — это разные сущности.
- Полная работа всех расширенных native-операций с настоящим аккаунтом: существующий код редактирования/веток/Canvas/расписаний не заменяет отдельное свидетельство там, где его нет. Проверять конкретный необходимый пробел, без повторов уже доказанной загрузки файлов.
- Совпадение названий не означает готовность: Files ≠ writable manager; GPT Scheduled Tasks ≠ Codex delayed messages; shared Reports ≠ автоматический Work Report; «Рассуждения» ≠ скачиваемый Markdown-артефакт.
